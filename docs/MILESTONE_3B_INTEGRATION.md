Exact schedule:

2. Prepare M3a blocking snapshot/timers/stored minima once (source-equivalent callback-free prepass). Phase and own position for lateral context are from before that runner longitudinal update.
3. Visit runner indices in order. A closed gate skips all MoveState target/speed/time/direction mutations. A partially opening gate passes FULL dt to lane movement; only longitudinal distance uses gate fraction. For each active runner apply MoveState with cached side permissions, then execute that runner existing longitudinal/HP/finish update with snapshot blocker identity/gap but live earlier-runner blocker speed. Reuse accepted primitives and state dtypes, not new equations.
4. After ALL runners move, run resolve_overlaps once on post-longitudinal positions and final lateral lanes, carrying force flags. Include rows whose self-movement was gate-closed. Keep source sequential sort/chained pushes with no rail clamp; write corrected lanes back to the authoritative field lane without adjusting the target/momentum state.
5. Complete the entire crossing tick, including later runners and overlap, then mark truncated if any runner finishes or all timeout. On subsequent calls freeze EVERY state leaf including lane targets, speed, timers, direction, force/moved flags. Use old truncation for current-pass masks, not the newly observed crossing flag. This remains the accepted restricted wrapper policy, not retail post-goal scheduling.
